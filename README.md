
# Code & Fries

**A cooperative educational puzzle game built with Unity and C#.**

Code & Fries was developed in 20 hours during monday.com's Hack the Gap hackathon.

## About the Game

Code & Fries is a cooperative puzzle game where two players guide Fries and Ketchup through challenging levels using visual programming commands.

Players must plan their movements, build command sequences, and work together to reach their goals.

The game introduces programming concepts through an interactive and playful experience.

## Key Features

- Visual block-based programming mechanics
- Two-character cooperative puzzle gameplay
- Command sequencing and simultaneous execution
- Interactive obstacles and environmental puzzles
- Educational gameplay focused on logical thinking

## Technologies

- Unity 6
- C#
- Unity UI
